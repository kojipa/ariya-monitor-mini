# Ariya Monitor Mini

日産アリアのバッテリー温度・残エネルギーなどを、小さな M5 の画面に出すプログラムです。
スマホのアプリ「Ariya Monitor」の小さい版で、車に置きっぱなしにして使えます。

[English](README.en.md)

## 書き込み(ブラウザだけでできます)

**https://kojipa.github.io/ariya-monitor-mini/**

パソコンの Chrome か Edge で開き、USB でつないだ M5 を選んで「書き込む」を押すだけです。
M5StickS3 に初めて書き込むときは、横の電源ボタンを2秒ほど長押しして、緑のランプが点滅したら離してください(書き込みモード)。

## 用意するもの

| | |
|---|---|
| 本体 | **M5StickS3**(おすすめ)または M5Stack Core2 |
| アダプター | ELM327 互換の OBD2 アダプター。StickS3 は **BLE か Wi-Fi** のもの(Bluetooth Classic だけのものは使えません)。Core2 はどれでも使えます |

## 出せる値

- 画面1: バッテリー温度(最高・最低)・冷却水温度・外気温
- 画面2: 残エネルギー(kWh)・SOC・電力(+充電/−走行)・12V

作者の車(B6 2WD 初期型)で確かめた値です。年式・グレードによっては出ない値があるかもしれません。

## 使い方

1. アダプターを車に挿して、車の電源を入れる
2. M5 を立ち上げると、近くの BLE と Wi-Fi を探して一覧に出します(OBD らしい名前は緑で上に出ます)
3. 画面の端の矢印のとおりに、横のボタンで「次へ」、正面のボタンで「決定」
4. 次からは選んだアダプターに自動でつながります

| ボタン | 押す | 長押し |
|---|---|---|
| 正面 | 画面切替 | 上下反転 |
| 横 | 明るさ | アダプターの選び直し |

## 安全について

車に送るのは、値を読み取る命令とアダプターの設定命令だけです。それ以外の命令はプログラムの中で止めていて、送りません。
それでも、使うのは自己責任でお願いします。運転中に画面を操作しないでください。

## 自分でビルドする

[PlatformIO](https://platformio.org/) を使います。

```
pio run -e sticks3 -t upload   # M5StickS3
pio run -e core2 -t upload     # M5Stack Core2
```
