Ariya Monitor Mini

日産アリアのバッテリー温度・残エネルギーなどを、小さな M5 の画面に出すプログラムです。ここからブラウザだけで書き込めます。

はじめに パソコンの Chrome か Edge で開いてください(Safari・Firefox・スマホでは書き込めません)。 車に送るのは読み取りの命令だけですが、使うのは自己責任でお願いします。

1. 機種を選んで書き込む

M5StickS3

おすすめ。BLE か Wi-Fi の OBD2 アダプターが要ります。

このブラウザでは書き込めません。パソコンの Chrome か Edge で開いてください。 https で開いてください。

M5Stack Core2

Bluetooth Classic・BLE・Wi-Fi のどのアダプターでも使えます。

このブラウザでは書き込めません。 https で開いてください。
  1. M5 を USB ケーブルでパソコンにつなぐ(充電専用ではなく、データも通るケーブル)
  2. 「書き込む」を押し、出てきた一覧から M5 を選んで「接続」
  3. 「Install」を押す。初めてのときは「消去してから書き込む」を選ぶ
  4. 1〜2分で終わります。終わったら M5 が自動で立ち上がります
M5StickS3 に初めて書き込むとき 買ったときのプログラムのままだと、一覧に出なかったり、書き込みが始まらなかったりします。そのときは書き込みモードにしてから、もう一度「書き込む」を押してください。
  1. USB でパソコンにつないだまま、横の電源ボタンを2秒ほど長押し
  2. 緑のランプが点滅したら離す(これで書き込みモード)
一度このプログラムを書き込めば、次からはこの操作は要りません。

2. 使い方

  1. OBD2 アダプターを車に挿して、車の電源を入れる
  2. M5 を立ち上げると、近くの BLE と Wi-Fi を探して一覧に出します(15秒ほど)。OBD らしい名前は緑で上に出ます
  3. 画面の端の矢印のとおりに、横のボタンで「次へ」、正面のボタンで「決定」
  4. 次からは選んだアダプターに自動でつながります

値の画面では、正面のボタンで画面切替(長押しで上下反転)、横のボタンで明るさ(長押しでアダプターの選び直し)。

出せる値

画面1:バッテリー温度(最高・最低)・冷却水温度・外気温
画面2:残エネルギー(kWh)・SOC・電力(+充電/−走行)・12V

作者の車(B6 2WD 初期型)で確かめた値です。年式・グレードによっては出ない値があるかもしれません。
