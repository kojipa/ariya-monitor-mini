ハードウェアの選び方

Ariya Monitor Mini を使うのに必要なもの(M5 本体・OBD2 アダプター・USB ケーブル)と、買える場所、気をつけることをまとめました。

必要なもの

  1. M5 本体:M5StickS3(おすすめ)か M5Stack Core2
  2. OBD2 アダプター:ELM327 互換のもの。本体によって使える通信方式が違います(下の表)
  3. USB ケーブル(USB Type-C):書き込み用と、車で電気をとる用。本体には付いていません
  4. パソコン:書き込みのときだけ。Chrome か Edge が動くもの

1. M5 本体を選ぶ

M5StickS3おすすめ

  • 手のひらより小さい(48×24×15mm、約20g)
  • 画面 1.14インチ
  • 電池 250mAh 内蔵
  • アダプターは BLE か Wi-Fi のもの

M5Stack Core2

  • 画面が大きい(2インチ、タッチ対応)
  • 電池内蔵
  • アダプターは どれでも(Bluetooth クラシック・BLE・Wi-Fi)
  • StickS3 の約2倍の値段

迷ったら M5StickS3 で大丈夫です。手持ちのアダプターが Bluetooth クラシック専用のときだけ、Core2 を選んでください。

3. OBD2 アダプターを選ぶ

アダプターの通信方式M5StickS3Core2
BLE(Bluetooth Low Energy)使える使える
Wi-Fi(パスワードなし)使える使える
Bluetooth クラシックだけ使えない使える
  • ELM327 互換と書いてあるものを選んでください。
  • 「iPhone 対応」と書いてあるアダプターは、たいてい BLE か Wi-Fi なので StickS3 でも使えます。Android 専用のものは Bluetooth クラシックのことが多いです。
  • クラシックと BLE の両方に対応したものもあります(作者の手持ちは、BLE 側が「OBD BLE」という名前で出てきます)。
  • Wi-Fi のアダプターは、アダプター自身が Wi-Fi を出すタイプで、パスワードなしのものに対応しています。
  • アダプターは同時に1台にしかつながりません。スマホのアプリと同時には使えません。

4. USB ケーブルの注意

書き込みには「データ通信ができる」ケーブルが要ります 100円ショップなどの充電専用ケーブルでは、パソコンが M5 を見つけられず、書き込みの一覧に出てきません。うまくいかないときは、まずケーブルを替えてみてください。
  • M5 側は USB Type-C です。パソコン側の差し込み口(USB-A か Type-C)に合うものを選んでください。
  • 書き込みのときは、USB ハブや延長ケーブルを通さず、パソコンに直接つなぐと失敗しにくいです。
  • 車では、車の USB 端子やシガーソケットの USB 充電器から電気をとります。車の電源を切ると USB の電気が止まる車が多く、そのときは M5 の中の電池で少しだけ動きます。
  • 車に付けるときは、短めのケーブルや L 字のケーブルにすると、ケーブルの重さで本体が外れにくくなります。

5. 車に置くときの注意

  • どちらの本体もリチウム電池が入っています。夏の車内(とくにダッシュボードの上の直射日光)に置きっぱなしにしないでください。
  • 運転中の視界や、エアバッグが開く場所をふさがない所に付けてください。
  • OBD2 アダプターを挿したままにすると、12V バッテリーが減ることがあります。長く乗らないときは抜いてください。
